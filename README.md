<br>
I build backend services and full-stack products where the **engineering details** matter — predictable request flows, consistent error handling, strict validation, clear module boundaries, and documentation that makes systems easy to consume and evolve.
 
My approach: keep systems **simple for users**, **structured for maintainers** — so features can be added without turning the codebase into a monolith of side-effects.
