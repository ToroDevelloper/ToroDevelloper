## Sobre mi

Soy un desarrollador full-stack con enfoque fuerte en backend. Me interesa construir sistemas utiles, documentados y mantenibles: APIs REST, autenticacion, autorizacion por roles, modelado de bases de datos, validaciones, documentacion tecnica y productos que conecten bien la logica del servidor con una experiencia usable.

Tambien soy fundador de **Kognia Global Schools SAS**, un SaaS escolar actualmente en desarrollo. Kognia representa mi paso de construir proyectos academicos y practicos a pensar como fundador: producto, arquitectura, seguridad, roadmap, datos sensibles y crecimiento por etapas.

Mi forma de trabajar es directa: entender el dominio, separar responsabilidades, documentar decisiones, validar entradas y construir por incrementos que se puedan probar y mejorar.

### Kognia School Platform API

**SaaS escolar multi-tenant**  
Proyecto fundador bajo **Kognia Global Schools SAS**.

Kognia esta pensado para colegios, academias y grupos educativos que necesitan una plataforma para gestion academica, calificaciones, LMS, biblioteca, prestamos de inventario y flujos asistidos con IA.

**Construido / planificado**

- API modular con NestJS y prefijo versionado `/api/v1`.
- Arquitectura de monolito modular para avanzar rapido sin perder limites de dominio.
- Modelo multi-tenant basado en `school_id` y contexto activo del colegio.
- PostgreSQL + Prisma para modulos academicos, LMS, biblioteca, inventario, archivos, auditoria e IA.
- Seguridad con JWT, refresh tokens, RBAC, validacion, rate limiting, Helmet, aislamiento por tenant y auditoria.
- Documentacion de vision, roadmap, ERD, arquitectura, seguridad, Git Flow y estrategia de pruebas.

**Logro principal**

Convertir una idea de producto en una base tecnica seria: roadmap, modelo de datos, seguridad, documentacion y arquitectura pensada para crecer.

**Reto principal**

Disenar una plataforma educativa donde la seguridad y el aislamiento de datos no son detalles secundarios. Se manejan datos academicos y personales, por eso cada modulo debe respetar permisos, contexto escolar y trazabilidad.

### NextLevelPC Store

**Tienda full-stack con arquitectura por servicios**  
El proyecto mas largo en el que he trabajado y uno de los que mas marco mi aprendizaje.

**Construido**

- Servicios de auth, catalogo, tienda, pagos, inventario, citas, resenas, sistema/contenido y frontend React.

- MySQL, scripts SQL, servicios compartidos, JWT y flujos administrativos.

**Logro principal**

Pasar de construir aplicaciones pequenas a razonar como producto completo: servicios, integraciones, autenticacion, pagos, inventario, frontend, despliegue y mantenimiento.

**Reto principal**

Mantener consistencia entre varios servicios mientras el proyecto crecia. Me obligo a mejorar estructura, comunicacion de APIs, manejo de estados y pensamiento end-to-end.

### SICFOR

**Sistema integral de gestion para un centro de formacion y cursos**  
Mi primer proyecto colaborativo grande, trabajado con un equipo de mas de 30 personas.

En SICFOR fui lider y dirigi gran parte del proyecto junto a los lideres de subgrupos. No trabajamos de la forma mas optima desde el inicio, especialmente por la curva de Git y la coordinacion entre modulos, pero logramos cumplir el objetivo.

**Construido**

- Backend con Node.js, Express y MySQL.
- Modulos frontend separados por grupos de trabajo.
- Gestion de estudiantes, cursos y mesa de ayuda/soporte.
- Uso de Cloudinary y carga de archivos en parte del sistema.
- Integracion de modulos desarrollados por distintos subgrupos.

**Logro principal**

Aprender liderazgo con restricciones reales: coordinar personas, integrar entregas parciales, resolver conflictos entre modulos y sostener el avance del proyecto hasta completarlo.

**Reto principal**

La coordinacion tecnica y humana. Fue una experiencia exigente porque no todos teniamos el mismo nivel con Git, estructura de proyecto o integracion, pero eso hizo que el aprendizaje fuera mas fuerte.

**Agradecimiento**

Gracias a todos los colaboradores que hicieron parte de SICFOR. Cada aporte ayudo a que un proyecto dificil se convirtiera en una entrega real y enriquecedora.

### CalcQuest

**Plataforma educativa con IA para Ecuaciones Diferenciales**  
Proyecto de aprendizaje gamificado que combina matematicas, interfaz grafica e inteligencia artificial.

**Construido**

- Aplicacion de escritorio con Python y PyQt6.
- Integracion con Google Gemini para tutor IA y generacion de apoyo.
- Modo socratico, pistas contextuales, retroalimentacion y analisis de errores.
- Generador de ejercicios, evaluacion diagnostica, misiones, flashcards, resumenes y seguimiento de progreso.
- Soporte matematico con SymPy/NumPy y persistencia local.

**Logro principal**

Unir IA, educacion y experiencia de usuario en un solo flujo. CalcQuest no se queda en resolver ejercicios: intenta guiar al estudiante y reforzar su aprendizaje.

**Reto principal**

Evitar que la IA solo entregue respuestas. El valor esta en orientar el razonamiento, detectar errores y mantener una experiencia que ayude a aprender de verdad.

### API-CINE

**API REST para gestion de cine**  
Sistema para usuarios, salas, asientos, peliculas, funciones, reservas, snacks, pedidos y pagos.

**Construido**

- Backend con Express y MongoDB/Mongoose.
- Autenticacion JWT por cookie o Bearer token.
- Middleware de autorizacion por roles.
- 9 entidades relacionadas.
- Documentacion Swagger/OpenAPI y coleccion Postman.
- Docker Compose para MongoDB local.
- Base de pruebas con Jest + Supertest.
- Carpeta frontend con React/Vite.

**Logro principal**

Construir una API de dominio completo, con relaciones reales y flujos protegidos, no solo CRUDs aislados.

**Reto principal**

Mantener claras las relaciones entre reservas, asientos, funciones, pedidos de snacks y pagos.

### Pet Health Backend

**API para gestion veterinaria**  
Backend NestJS para historia clinica, consultas, vacunacion, inventario, notificaciones, usuarios y flujos por rol.

**Construido**

- NestJS + TypeORM + MySQL.
- JWT, control por roles y bloqueo de cuenta tras intentos fallidos.
- Modulos de propietarios, mascotas, especies, razas, citas, consultas, historia clinica, vacunas, inventario, reportes y auditoria.
- Swagger en entorno de desarrollo.
- Seeder inicial para roles, especies, razas y usuario administrador.
- Validaciones y formato de errores consistente.

**Logro principal**

Trabajar una estructura NestJS mas grande, con modulos de negocio y reglas donde importan los permisos, la agenda, el historial clinico y el inventario.

**Reto principal**

Ordenar un dominio amplio sin perder claridad en responsabilidades, endpoints, validaciones y roles.
